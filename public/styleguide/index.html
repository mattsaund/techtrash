Type

Four sizes and one for the Welcome screen, two weights, three faces. Nothing is smaller than 11px, and 11px is for chrome only.

ui, 11/13: menus, buttons, fields, labels File Edit View Favorites Tools Help
body, 13/20: anything read, and window titles in bold tech, space, computers, music and junk
head, 16/22: a heading in a document What goes here
big, 20/26: a headline, the start button, a name on the Welcome screen Hello, world
display, 36/44: the site's name on the Welcome screen, nowhere else techtrash
mono, at body size: Notepad, the command prompt, code C:\> dir /w
