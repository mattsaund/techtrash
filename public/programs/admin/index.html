Lock

While it's locked, only you can change anything on it. Everyone else can still look, open things and move windows around, but not save, rename, move, throw away or set the wallpaper. They see a padlock by the clock.

The disk

A visitor is a tag: their internet address, scrambled, so the same person always has the same one and nobody can work out the address from it. Visitors kept out can still look, but can't change anything.
